## Summary

This plan outlines the technical approach to building and integrating a Retrieval-Augmented Generation (RAG) chatbot into the Docusaurus book. The chatbot will provide readers with instant, context-aware answers to their questions about the book's content, with options for both general and text-selection-based queries.

## Technical Context

**Language/Version**: 
- Backend: Python 3.11
- Frontend: Node.js 18.x (with TypeScript)

**Primary Dependencies**: 
- Backend: FastAPI, Uvicorn, Qdrant-client, psycopg2-binary, Pydantic, a library for LLM interaction (e.g., `openai` or `anthropic`).
- Frontend: React 18, ChatKit, a library for making API calls (e.g., `axios`).

**Storage**: 
- Vector DB: Qdrant Cloud (Free Tier)
- Relational DB: Neon Postgres for user IDs and chat history.

**Testing**: 
- Backend: `pytest`
- Frontend: React Testing Library, `jest`

**Target Platform**: 
- Backend: Vercel or Render (Linux serverless environment)
- Frontend: GitHub Pages (static site hosting)

**Project Type**: Web application (frontend + backend)

**Performance Goals**: 
- 90% of answers delivered in < 5 seconds.
- Chat widget loads in < 2 seconds.

**Constraints**: 
- Must use the specified technology stack.
- Initial version will not have a user authentication system.

**Scale/Scope**:
